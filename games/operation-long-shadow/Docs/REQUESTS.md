# Cross-package requests

For anything you need in a folder another package owns (TECH_PLAN §11.1 ownership table), except Core (use `Docs/CORE_CHANGES.md`). Append an entry; the owner picks it up, does it and updates the Status line. Never edit the other package's files yourself.

Entry format (append at the bottom, newest last):

```
## <YYYY-MM-DD HH:MM> <from WPxx> -> <to WPyy> <short title>
- Need: what exactly (file, asset id, prefab, marker id, menu item, API in their assembly)
- Why / when: which beat or feature, and whether you are blocked or have a workaround
- Status: requested
```

Typical requests: a new marker id in `Assets/_Game/Data/markup_ids.csv` (WP10; Appendix A and the CSV change together), a new asmdef package reference (WP00/WP11: land.py refuses new asmdefs and LongShadow.* references outside TECH_PLAN §4.3), a LIB_* entry, a cue id, a prefab slot.
