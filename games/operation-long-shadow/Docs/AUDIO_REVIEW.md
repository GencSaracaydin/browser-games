- Takes generated and verified: 570 for 176 take families; families with a fully passing take: 176/176.
- Checks per take: normalised WER vs the line text (numbers expanded, fuzzy match for proper nouns), delivery-tag words spoken aloud, cut-off (last word missing, or the raw file still loud at its end), clipping in the raw TTS output, speech rate, long internal gaps, and pitch against the other takes of the same line. Invented-language lines: duration vs syllable count, a **sound-alike check** (every transcript word is looked up with `wordfreq` in 27 top-20/priority languages; a word with zipf ≥ 3.2 rejects the take), and letter similarity between transcript and spelling to prefer the take that says what we wrote.
- **Independent audit** (`Tools/audio/vo/vo_audit.py`, re-measures the files on disk): 305/305 expected clips present, 165 envelopes, 470 index rows; LUFS -18.16 … -18.0, true peak max -1.15 dBTP, lead max 60 ms; every file mono 48 kHz 16-bit; DRY/RADIO (and INTERCOM/RADIO) pairs sample-synchronous; no stale files. Failures: **0**. Estimated build size 5.4 MB, 18.2 KB per clip on average (budget ≤ 30 KB average).
