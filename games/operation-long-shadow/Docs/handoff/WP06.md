## 2. Public APIs

- **`IAudioService` (AudioService).**
  - Playback: `Play`, `Play2D`, `PlayLoop`/`StopLoop` (a handle; `StopLoop` also stops attached one-shots), `PlayAttached`, `PlayWeaponShot(weaponId, pos, isPlayer)` (call once per round).
  - Listener and mix: `SetListenerOverride(t)` (null returns to the player), `CurrentZone`, `Tinnitus(s)`, `SetCategoryGain(AudioCategories.X, linear)` (`Master` scales everything), `Duck(category, dB, seconds)` (the deepest duck wins), `HasCue`.
  - Extra public member: `PlayPitched(cue, pos, volume, pitch)`. A Core request is filed for it.
  - Cue ids are ASSET_MANIFEST ids. Sliced takes keep their slice in the id (`SFX_WPN_AK_RELOAD_MAGOUT`), and `SFX_WPN_SHELLS` is an aggregate of the SAND and STONE sets.
- **`IVOService` (VOManager).**
  - `Play(id, VOOptions)` returns a handle. It returns 0 for an unknown line or a line spent before the restored checkpoint. A repeated request returns the same handle.
  - Status and control: `IsPlaying`, `IsNetBusy`, `Stop`, `StopAll(fade)`.
  - Barks and clicks: `PlayBark(id, speaker, team)` (Legion barks are DRY within 30 m and FAR beyond, voice A/B stable per speaker); `PlayClicks(1..3, speaker)` (`SFX_RADIO_CLICKS_n`).
  - `Amplitude(speakerId)` (0..1, 30 Hz envelope), `PrepareWindow(from, to)` (also automatic on BeatStarted), `HasPlayed`, `HasLine`, `Duration`.
  - **`VOOptions`:**
    - `Speaker`: the 3D source and the dry/radio distance. Squad lines resolve it through `ISquadService.Member`.
    - `ForceRadio` / `ForceDry`.
    - `RadioSwitchTime`: with `ForceDry` + `Speaker`, G9. 0 uses the line's own value; D039 = the first "Seven" from its token onsets.
    - `Delay`, `Interrupt`, `NoSubtitle`, `Volume`, `Priority`.
- **`IMusicService` (MusicDirector).**
  - Layered cues by base id: `PlayCue("MUS_02_MARKET", layer, fade)` (0 = LO/LOW, 1 = HI/FULL); a layer id such as `MUS_02_MARKET_HI` also works.
  - `SetLayer(layer, fade)` changes on the next bar line. `Stinger(id)`, `Stop(fade)`, `HardCut()`, `CurrentCue`, `CurrentLayer`.
- **Mission events the package listens to** (string literals; constants in `LongShadow.Audio.Core.AudioEvents`, Core mirror requested):
  - Ambience: `Ambience.Booth.On` / `Ambience.Booth.Off`, `Ambience.Mute` / `Ambience.Unmute`.
  - Numbers broadcast: `B9.Numbers.Start` / `B9.Numbers.Stop`.
  - PA horns: `PA.Siren`, `PA.Play.<cueId>`.
  - It raises `B9.TransmittersDown` itself.
  - Defaults without any event:
    - CinematicStarted(Intro|Outro) turns booth mode on; `Intro.ControlToPlayer` and CinematicEnded(Intro) turn it off.
    - BeatStarted(9) and CP9 start the numbers broadcast.
    - InsertStarted/InsertEnded pause and resume the world.
- **Components for level and prefab builders:**
  - `LoopEmitter.Configure(cue, sWindow, beatFrom, beatTo, cullDistance, strikeOnPracticals)` and `ConfigureEvents(start, stop, destructibleId)`.
  - `CivilianEmitter.Configure(kind, beatFrom, beatTo)`.
  - `AmplitudeFollower.Configure(...)`.
  - `CharacterFootsteps`: added automatically.
  - `AmbienceDirector.SetBoothMode`, `SetMuted`, `ForceContext`/`ClearForcedContext` (dev).
  - `PAHorns.PlayFromHorns(cue)`.
- **Editor (batch-callable static methods):**
  - `AudioSetupMenu.BuildAll()`, `.BuildSystemsPrefab()`, `.ReportCoverage()`.
  - `AudioLibraryBuilder.Build()`.
  - `DialogueImporter.Import()` / `.Validate()` / `.Run(write, out errors)`.
  - `AudioTestSceneBuilder.Build()`.

## 5. Known gaps and risks

- **No Unity run yet.** No editor slot was available to this code agent, so the EditMode tests have not been executed, only compiled. The integrator runs them (step 6). The edit-mode integration tests use generated `AudioClip.Create` clips and a test clock (`AudioRuntime.SetClockForTests`); they call `Initialize()` and `Tick()` directly because Awake/OnEnable/Update do not run in edit mode.
- **WebGL audio behaviour is unverified:**
  - `PlayScheduled`/`SetScheduledEndTime` and setting `timeSamples` on compressed clips.
  - If a browser misbehaves, set `ScheduledLooper.SchedulingEnabled = false`. Loops then use `AudioSource.loop`, and the AAC priming click may come back.
  - The listener-pause restart of scheduled loops (pause menu, inserts) is designed for the WebAudio clock and needs a web test.
- **Sample rates on the web:** Unity 6000.6 ignores the 22 050/24 000 Hz overrides on WebGL (WP00-B). Loop regions are stored in seconds, so the 44.1 kHz AAC output keeps the loop bodies. Download size comes from the build report (DoD total ≤ 18 MB, WP11 audit).
- **Mix balance is a first pass.** The `CueDefaults` levels and distances, the `AmbienceTable` levels and the duck depths are reasoned values, not tuned by ear (O4 waived). Tune them in `CueDefaults`/`AmbienceTable`, then re-run Build Audio Library. Weapon layers stay at volume 1.0 per WP06_SFX's headroom note.
- **NPC footsteps:** surface detection uses one raycast per step within 35 m. The terrain layer grid is 64 × 64 per TerrainData (a one-off sample at first use). A body that never raises foot events gets a stride clock instead.
- **Booth tone ownership:** booth tone during inserts and booth cinematics is played by the AmbienceDirector. If WP09 also plays `AMB_ROOMTONE_BOOTH`, one of them should stop. Booth mode is idempotent, so raising `Ambience.Booth.Off` is enough.
- **Envelopes are per-clip-peak normalised.** A whispered line moves the needle as much as a shouted one.
- **Music:** no automatic combat intensity. Layers are script-driven (GDD §7.0 says when HI plays). `EXTRA_*` cues (`SFX_DOWNWASH_SAND`, `SFX_CINE_RAMP`, `SFX_WPN_M60D_OVERHEAT`) have mix rules but were not in the ready tree at the time of writing.
- **Dev panel:** `AudioAuditionPanel` (IMGUI) allocates per frame by design (dev scene only, never built).
