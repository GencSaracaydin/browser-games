### Runtime scripts (TECH_PLAN §7.1)

- **`Bootstrap`** runs the boot flow of §5.2:
  1. Addressables initialises.
  2. `S_Persistent` loads and becomes the active scene.
  3. `S0_Booth` loads.
  4. `IVOService.PrepareWindow(0, 1)` runs.
  5. The gate turns ready. `S9_TownFar` and `S1_Approach` start loading behind it (D20).
  6. On the click it resumes audio, takes pointer lock and optional fullscreen, enables pausing, then calls `StartMission()`, or `ResumeFrom(cp)` when the URL has `?cp=`.

  `?autotest=1` skips the click. It raises the mission events `Boot.PersistentLoaded`, `Boot.GateReady`, `Boot.Autotest`, `Boot.MissionStarted` and `Boot.Failed` (constants in `BootEvents`). A black `BootCamera` (renderer 1) draws only while no other camera exists. A boot phase that runs past its timeout puts a stall error on the gate.
- **`LaunchOptions`** parses the URL query and hash: `cp`, `dev`, `autotest`, `nolock` and `perf`. A QA build turns `dev` on. In the editor the values come from `DevStart`. `ISettingsService.GetValue("?cp")` reads them.
- **`WebBridge` and `WebNative`**: `WebNative` holds the `DllImport`s (behind `UNITY_WEBGL && !UNITY_EDITOR`, with editor fallbacks). `WebBridge` is the `SendMessage` receiver: `OnPointerLockChanged`, `OnPointerLockError`, `OnVisibilityChanged`, `OnFullscreenChanged` and `OnHtmlGateClicked`.
- **`DisplayInfo`** implements `IDisplayInfo`: the DPR as the engine renders it (capped at 1.5 by the template), the iframe flag, `CanvasPixelSize` and the lock state.
- **`PointerLockController`**:
  - Sets `WebGLInput.stickyCursorLock = false`.
  - Asks for `unadjustedMovement` first, then a plain lock.
  - Honours Chrome's ~1 s re-lock cooldown (it retries, and it arms the page so the next click locks).
  - `ExpectLock()` covers the case where the page already asked inside the gesture.
- **`PauseService`** implements `IPauseService`:
  - Pausing pushes time scale 0 at priority Pause, sets `AudioListener.pause`, locks all input and raises `PauseChanged`.
  - Triggers: losing the pointer lock (Esc), the Pause action, or the tab becoming hidden.
  - `Resume()` must be called from a click.
  - `RelockCooldown` feeds the "Click to resume" overlay.
- **`TimeScaleService`/`TimeScaleStack`** implement `ITimeScaleService`. The request with the highest priority wins; between equal priorities, the most recent wins. `SetScale` changes a live request (for ramps). The physics step shrinks with the slow-down.
- **`InputLockService`/`InputLockSet`** implement `IInputLock` with reference-counted channel locks.
- **`SettingsService`** implements `ISettingsService`:
  - Storage: localStorage (`ls.settings`). Each write is try/catch, with an in-memory shadow when the browser refuses. The editor uses PlayerPrefs.
  - Apply and save: `Apply` sanitises, notifies and saves 0.5 s later.
  - Difficulty takes effect at the next checkpoint.
  - Safari defaults to performance mode on the first run.
- **`QualityApplier`** (D21):
  - The automatic render scale is the largest of {1, .9, .8, .75} that keeps the canvas at ≤ 2.1 MP; it is re-checked on resize.
  - Performance mode turns SSAO off, uses 2 cascades, caps shadows at 50 m and render scale at 0.8.
  - Brightness, film grain and motion blur come from runtime volumes (`OptionsVolumes`, one set per volume layer: Default and Booth).
  - The fullscreen option is applied when it changes.
  - It sets `Application.targetFrameRate = -1`.
  - In the editor it restores the URP asset when play mode ends.
- **`SectionStreamer`** implements `ISectionStreamer`:
  - `Addressables.LoadSceneAsync(scene name, Additive)`, one operation at a time, with request coalescing.
  - After every load and unload it calls `LightProbes.TetrahedralizeAsync()`, logs the time and memory (`MemoryStats`), and raises `SectionLoaded`/`SectionUnloaded`.
  - `WaitLoaded` re-requests a section if someone unloaded it in the meantime.
  - A failed section counts as loaded (with an error), so beat scripts never hang.
  - In the editor it falls back to the scene path, then to the dev placeholder.
- **`PoolService`** implements `IPoolService`: one `ObjectPool<GameObject>` per prefab. Idle instances wait under an inactive root, `Prewarm` creates them ahead of time, and despawns can be timed. It allocates nothing per frame after warm-up.
- **`AddressablesRemap`/`PublishedNames`** provide the runtime `InternalIdTransformFunc` for published web builds. When the page sets `LS_ASSET_SUFFIX`, it appends `.wasm` to every bundle or hash URL whose extension the host does not serve.
- **`HtmlClickGate`** is the fallback `IClickGate`, used until WP08's gate exists. It drives the template's HTML loader on the web and draws an IMGUI gate in the editor.
- **`DevStart`** is an editor-only query string and click skip on `S_Boot`.

### Template and jslib

- **Template:**
  - DPR cap 1.5.
  - Dark CRT loader with five-digit number groups.
  - The ready line is exactly GDD §8.1 `SESSION 12 // SUBJECT S-3 // CLICK TO BEGIN` with a blinking cursor. The whole gate is the click target and can be focused from the keyboard.
  - Its own `errorHandler` plus `unhandledrejection`/`error` filters: pointer-lock and fullscreen refusals are ignored, real errors go to a CRT fault panel or a toast, and nothing calls `alert()`.
  - `HTMLCanvasElement.prototype.requestPointerLock` is wrapped to try `{unadjustedMovement:true}` first, then a plain lock, and it never rejects.
  - It checks for WebGL2 and WebAssembly before downloading.
  - Markers patched later: `/*LS:VARIANT*/` (by WebBuild), `/*LS:ASSET_SUFFIX*/` and `/*LS:SERVED_EXT*/` (by publish_plan).
- **jslib (27 functions):** DPR, pointer lock (unadjusted first, then plain), exit/is-locked, a gesture arm (lock/fullscreen/audio on the next pointerdown or keydown), fullscreen, audio resume, localStorage get/set/remove/available (try/catch), iframe flag, URL query, user agent, `LS_SetSmokeResult` (sets `window.LS_SMOKE_RESULT`), asset suffix and served list, build variant, loader progress/ready/visible/error, and heap bytes. Callbacks arrive through `SendMessage("WebBridge", …)`.

```
python3 Tools/build/publish_plan.py --selftest
```

What `publish_plan.py` does:

1. Builds the mirror. Every file whose extension the host does not serve gets `.wasm` **appended**: `Build/<h>.data.unityweb.wasm`, `x.bundle.wasm` (which still matches the loader's `/\.bundle/` IndexedDB rule) and `catalog.hash.wasm`.
2. Patches the mirror's `index.html`: both the `Build/x` and the `buildUrl + "/x"` reference forms, plus the markers.
3. Patches the Addressables JSON catalog's internal ids.
4. Leaves out foreign files, `*.manifest` and `AddressablesLink/`.
5. Checks the host limits.
6. Diffs against the last published list. Unchanged files are skipped and vanished paths become `null` removals in batch 1 (D22).
7. Packs batches of ≤ 60 MB and ≤ 250 entries (first-fit decreasing). `index.html`, the page, goes with every batch.

Each batch in the plan is ready for the Artifact tool as `publish(file_path=batch.file_path, files=batch.files)`. Batch 1 creates the artifact; later batches pass its `url`. The publish itself needs the user's approval and is the orchestrator's job (O5).

## 3. Editor steps for the integrator (editor holder), in order

1. **Land.** These three runs are the LAND agent's, not WP01's in this phase:

3. **Apply the template.** Run **LongShadow/Setup/Apply Project Settings**. It switches `WebGL.template` to `PROJECT:CovertOps`; everything else should report `=`.
4. **Set up Addressables.** Run **LongShadow/Platform/Setup Addressables**. It creates the settings and adds `ENABLE_JSON_CATALOG` to the WebGL defines, which triggers a recompile and domain reload: wait, then check the console again.
5. **Build the scenes.** Run **LongShadow/Platform/Build Boot Scene (S_Boot)**, then **LongShadow/Platform/Build Placeholder Scenes**.
6. **Group rules.** Run **LongShadow/Platform/Apply Addressables Group Rules** and check its log for warnings.
7. **EditMode tests.** `Unity_RunCommand`: `LongShadow.Core.Editor.TestRunnerBridge.RunEditMode("LongShadow.Tests.EditMode.Platform")`. Expected: all green. They log expected warnings, so clear the console afterwards. The PlayMode suite `LongShadow.Tests.PlayMode.Platform` (pause flow, time-scale stack) needs a PlayMode run from the Test Runner window or TestRunnerApi.
8. **Play in the editor.** Open `S_Boot` and press Play. Expected behaviour:
   - Addressables play mode "Use Asset Database".
   - The placeholders load, and the IMGUI gate shows "CLICK TO BEGIN".
   - The log shows "No IMissionDirector registered" until WP07 lands; that is expected.
   - `DevStart` on `BootRoot` takes a query such as `cp=CP5&dev=1` and can skip the gate.
9. **Build.** Use **LongShadow/Build/Web Release**, or synchronously:
   `LongShadow.Platform.Editor.WebBuild.BuildAndLog(LongShadow.Platform.Editor.WebBuildOptions.Release())`
   - Plan for about 5 minutes cold (research: 279 s) and 2-3 minutes incremental.
   - Read `Builds/Web_build_log.txt`.
   - If it stops with "ENABLE_JSON_CATALOG was just added", wait for the recompile and run it again.
   - If only the duplicate check fails and the group-rule log does not explain it, run once with `new LongShadow.Platform.Editor.WebBuildOptions { FailOnDuplicates = false }` and file the duplicate list with WP11.
10. **Verify the build (TECH_PLAN §10.5).**
    - `python3 Tools/build/validate_build.py` and `python3 Tools/build/validate_build.py Builds/Web_publish --published`.
    - Serve `Builds/Web_publish` (the served-name mirror) with `python3 -m http.server <8800-8899> --bind 127.0.0.1` and open it in a new Browser pane tab. Expected sequence: CRT loader, then the number groups fill, then `SESSION 12 // SUBJECT S-3 // CLICK TO BEGIN`. The click hides the gate. No alert.
    - Repeat with `?autotest=1&nolock=1`.
    - Stop the server.
    - Real Chrome and Safari checks are manual: pointer-lock grant, `unadjustedMovement`, the Esc → pause → click-to-resume path, and that settings persist across a reload and fall back in a private window.
11. **Publish.** This needs the user's approval and is done by the orchestrator. Use `Builds/Web_publish_plan.json` batches, then run `python3 Tools/build/publish_plan.py --mark-published`.
