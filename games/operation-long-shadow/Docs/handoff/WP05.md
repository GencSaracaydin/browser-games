## 2. Public APIs (contract for other packages)

- **`ICharacterBody` = `HumanoidBody`** on the root of every non-FP body. `PlayAction(id, done)` accepts every Core `ActionIds` id and the WP05 extras (`Fire, SitIdle, SitTalk, SitArmsCrossed, PhoneTalk, ReachToggle, HeadLift, GoLimp, LookAround, Kneel, CheckWatch, OneFinger, Wave, Talk, Stop`; Core change requested, pass the literals until then). Loops call `done` as soon as they are established, timed and one-shot actions call it when they end, and an unknown id logs once and calls it at once. Arms actions (FistHold, Photograph, CrackChemlight, Reload, Throw, HandSignal, RpgRaise, HandsetToEar, RaiseCamera, PhoneTalk, ReachToggle, CheckWatch, OneFinger, Wave) do not end a full-body action. A full-body action ends both. `MoveTo` ends loops and full-body actions but not traversals. `AnimEvent` raises `Foot_L/Foot_R/ThrowRelease/MagOut/MagIn/ActionHit/ActionEnd`.
- **Extra hooks (no assembly reference needed):** `SendMessage("SetPerch", bool)`, `SendMessage("PlayFireRecoil")`. AI shots whose `ShotEvent.Origin` is within 0.6 m of the body's muzzle kick it automatically. Booth: `SetSession11(bool)`, `SetHeadVisible(bool)`, `SetCuffed(bool)`. Shadow: `SetCinematicMode(bool)` (also automatic on the first ICharacterBody call) and `SetRenderVisible(bool)`. Jaw: `SetJawOpen(0..1, <0 = VO envelope)`.
- **`IFirstPersonBody`** is registered by `FirstPersonBodyHub` while PFB_Calder_FP or the booth Calder exists. `PlayWatchCheck(1.2f, done)`, `PlayPistolRise(3f, done)`, `SetFists(bool)` (also drives the booth Calder). It completes immediately, with one log line, when no FP arms exist.
- **Animator contract:** every WP05 controller has all of `CharacterAnimIds.AllParameters`, which is Core `AnimatorParams` plus `HandPose, Hold, ActionHold, ArmsAction, ArmsTrigger, ArmsHold, Turn, IdleSet`. Layers: `Base`, `Arms`, `Hits`, `Hands`. State tags: `Locomotion`, `Action`, `Procedural`, `Death`. WP02's PlayerShadowProxy only needs `Speed, Crouch, Aim, Airborne`.
- **Layers:** enemies and squad use layer Character for the capsule and renderers, and Hitbox/SquadHitbox for the bone colliders (Ragdoll after death). Shadow uses Player and ShadowsOnly. FP uses Viewmodel, rendering layers World + Cabin + Viewmodel, and no shadows. Booth uses layer Booth and rendering layer Booth. Squad, Calder and Magpie also get the Cabin rendering layer.
- **Library:** `LIB_CharacterWeapons` (`CharacterWeaponLibrary`, entries by Core `WeaponIds`), read at runtime through `Libraries.TryGet`.

## 5. Known gaps and risks

- **Not executed in the editor.** The builders and tests are compile-checked only, so expect a first-run fix-up slot. The riskiest API paths are the RocketboxImporter's delayed second import (humanDescription replacement), `ModelImporter.sourceAvatar` set in OnPreprocessModel, edit-mode PlayableGraph sampling (speed probe and validator), and `AvatarBuilder` for the mannequin. Each one degrades with a log line: no fix → Unity's auto-map; no sampling → nominal speeds and a "-1" IK measurement.
- **Animation Rigging is not used** (decision logged): the IK is custom LateUpdate solvers. GDD/TECH_PLAN wording asked for Multi-Aim/Two-Bone IK constraints.
- **UAL/SAC avatars:** SAC clips copy SK_SAC_DefaultMaleRig's avatar (its bind is a T-pose, per the content notes). The UAL libraries build their own avatars with Bake Axis Conversion ON. If UAL clips hold the arms high, set Enforce T-Pose once in that FBX's Rig tab (the importer keeps the avatar). The UAL "Root Motion Node = Rig/root" note is not applied: Humanoid root motion uses the body centre, and only ClimbUp_1m and Jump_Land use the RM file.
- **Seat heights:** seated clips are grounded by the feet (pelvis joint 0.52-0.65 m by clip, WP05_ART §5). WP09 must place the booth chair and helicopter bench to match, or offset the body root.
- **Missing motions:** there is no JogBack clip, so backward running blends the walk-back clip. Ladder climbing has no clip and uses a stand-in.
- **PFB_Harrou is editor-only** (8 mm footage pre-render, D14): keep `Prefabs/Bodies/PFB_Harrou` and `Art/Models/Characters/Harrou` out of Addressables groups.
- **Raw Rocketbox animation FBX** are not supported (they must go through `Tools/characters/build_clips.py rocketbox`). Raw avatars are supported.
- **Placeholder muscle signs** (PH_* clips, muscle-curve finger poses) follow Unity's documented conventions but were not checked visually. They only show for slots without content clips.
- **Budgets:** the validator reports triangles including the merged hat/rig props, and only notes when they exceed 15 k (Calder 15.4 k) without failing. The texture budget per body is not checked here (TextureImportRules / validate_assets).
- **Override controllers** are role variants on a shared AC_Soldier. Variants whose base clip is shared by another slot are skipped and listed in the controller report.
- **Facial animation:** only the jaw flap. There are no blend shapes and no eye blinks.
- **Corpses** sink and despawn after 30 s rather than fading (opaque URP materials).
- **Cover poses:** stand cover = idle and crouch cover = crouch tree. Lean is a procedural spine roll; there are no lean clips.
