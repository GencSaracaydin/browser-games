## 2. The rules in one page

Managed roots: `Assets/_Game/Art/{Textures,HDRI,Models,Animation}`, `Assets/_Game/UI/Sprites`, `Assets/_Game/Audio`, and the mirror root `Assets/__ImportRuleTest/` (tests only). Nothing else is touched (research scaffolding, packages). Opt out per asset with `ls-import:manual` in the importer's userData (for importers such as WP05's RocketboxImporter that own their settings). Rules re-apply on every import, so hand edits do not survive a reimport.

**Textures (§3.10)**, all with an explicit WebGL override, Read/Write off, streaming mips off, Max Size never above the source (rounded up to a power of two):
- Suffix `T_<Name>_<BC|N|M|E|H|A>`: BC sRGB DXT1/DXT5 crunched by *real* alpha (an RGBA PNG whose alpha is all opaque gets DXT1) and alpha-is-transparency when alpha is used; N normal map DXT5(nm); M linear DXT5 (A = smoothness); E sRGB, 512 for surfaces; H linear ≤ 1024 (16-bit H = editor-only R16 data, Read/Write); A linear DXT1.
- Caps: manifest budget of the folder ("512 maps in game", "hero prop: 1024", "1024 atlas"...), then `asset_budgets.json` lists. Env 1024 (4 hero sets 2048), ground sets aniso 8; Props 512 (13 hero 1024); Weapons q80, FP 2048 / mask 1024 / magazine 512, world 1024; Characters q70 (heads q80), squad 1024, Hollis head 2048, enemies/minor 512, character props 512 (PRC-77 1024), fabrics 1024; Vehicles BC per manifest (2048 technical/heli), N/M ≤ 1024; Vegetation per manifest; Decals DXT5 clamp; FX 1024 (emissive FX q70); Images 1024 (`_FS` 2048); UI sprites per manifest/512, RGBA32 when ≤ 128 px or not block-aligned; `HDRI/Runtime` 2048 DXT1 q70 Kaiser, repeat/clamp; `HDRI/EditorOnly` cube lat-long RGBAHalf (never ship).
- Cards: leaves/grass/foliage/cards/impostor/blur sets clamp every map; alpha-tested ones keep coverage in the mips; impostors ≤ 256. `Env/_Shared` and `Weapons/_Shared` detail maps are linear 512 (URP/Lit needs linear detail albedo).
- Images: intel card photos (`T_Intel*`) and `*_UI`/`*_Overlay` import as Sprites, no mips; CRT/cinematic plates no mips and keep 4:3 (NPOT None) when the scaled size stays a multiple of 4; documents (`*Page*`, `*Document*`, `*Dossier*`, `_3D`) mips + power-of-two; `concept_*`/`*_Reference` editor-only 2048 DXT1 (uncrunched).
- `Decals/poster_art` 2048 (folder override in `asset_budgets.json`).

**Models (§3.11)**, all: file scale on, global scale 1, bake axis conversion off (Blender FBX metres, axes baked), no cameras/lights/visibility, Read/Write off, normals Import, tangents Mikk, no colliders:
- Props/Vehicles/Vegetation: anim None, compression Medium, Mesh LOD (LOD0 + 2) unless the file has authored `*_LOD1..` meshes (Unity builds the LODGroup), lightmap UVs only for `_LM` files and `model.lightmapped_props` (covered_car, namaqualand_boulder_04, rock_face_01).
- Weapons: `_FP`/`_Mag` compression Off, no Mesh LOD; world (`_W`/`_World`/unmarked) Medium + Mesh LOD.
- `Characters/**` (not `Characters/Props`): **Humanoid**, avatar created from the model, materials None (WP05 builds them), compression Off, blend shapes on. `Characters/Props/**`: static, Medium, no Mesh LOD.
- `Animation/Clips/**`, `Animation/Poses/**`: Humanoid, own avatar, clips imported, Optimal, keyframe reduction 0.5°/0.5 %.
- Kit/Terrain/Backdrop: lightmap UVs, Medium, no Mesh LOD.
- Static meshes keep their material slots (ImportViaMaterialDescription) so `ModelMaterialBinder` can remap them (decision).

**Audio (§3.12)**: SFX one-shots (Weapons incl. `Weapons/Far`, Impacts, Foley, Footsteps, Explosions, Whizz, Synth) mono, Decompress On Load, preload, q70; SetPieces/Vehicles mono, Compressed In Memory, preload, q60; UI mono, DOL, preload, q60, 22050; Ambience stereo, CIM, no preload, background, q50; VO RADIO/INTERCOM/HF_AM/GREYCOAT_SQUELCH/PA_HORN mono, CIM, no preload, background, q60, 22050; VO DRY/FAR/SCRAMBLER/TAPE/CLEAN/BOOTH/ROOM_SPEAKER the same at q70, 24000; Music stereo, CIM, no preload, background, q60. Normalize off everywhere. **Measured: Unity 6000.6 encodes every clip for WebGL as AAC 44.1 kHz from these default settings and accepts no WebGL override; the 22050/24000 overrides only affect other platforms** (see DECISIONS). The report/self-test check the imported AAC output.

## 3. Public API (editor; namespace `LongShadow.Core.Editor`)

Everything a menu does is callable from `Unity_RunCommand`:

```csharp
// Import rules
AssetPipeline.ReapplyAllGameAssets();                 // force-reimport every managed asset (after a rule/budget change)
AssetPipeline.ReapplyRules("Assets/_Game/Art/Textures/Env/sand_01");
ImportRuleReport.Run();                               // -> Logs/import_rules_report.txt (Summary: Checked/Mismatched/OptedOut)
ImportRuleReport.Check(assetPath, out bool mismatch, out bool optedOut); // one line: rule + differences
TextureRules.Resolve(assetPath, TextureSourceProbe.Probe(assetPath));    // what a texture will get (also ModelRules/AudioRules.Resolve)
ReadyContentCheck.CompareNotes();                     // ready import notes vs rules -> Logs/import_rules_vs_ready_notes.txt
ReadyContentCheck.ExportRuleTable();                  // -> Logs/import_rules_table.tsv (for validate_assets.py --check-mirror)
ImportRuleSelfTest.Run();                             // or Stage() / Verify() / Cleanup() separately for long runs

// Materials (idempotent: existing materials are updated in place, GUIDs kept)
MaterialFactory.BuildFromReadySpecs();                // every RawAssets/*/ready/**/*material*.json row whose textures landed
MaterialFactory.BuildFromSpecFile(path, skipUnlanded: false);
MaterialFactory.BuildAllInFolder("Assets/_Game/Art/Textures/Props");      // sets named T_<Name>_{BC,N,M,E,H} -> M_<Name>
MaterialFactory.BuildFromTextureSet(TextureSet.FromMember(texPath), new MaterialOptions { TileMeters = 1.5f, DetailNormal = "...", DetailTiling = 6f });
MaterialFactory.Build(MaterialSpec spec);            // one spec row (URP/Lit, Shader Graphs/Decal or any shader)
ModelMaterialBinder.BindAll();                        // remap model slots to materials by name (explicit map > spec assign_to_slot > M_<slot> > M_<model>)
ModelMaterialBinder.Bind(modelPath, explicitMap);
MaskPacker.PackFromArm(armPath, "Assets/.../T_X_M.png", heightPath);       // D4: R metal, G AO, B height/0, A smoothness
MaskPacker.PackFromGltf(mrPath, outPath, aoPath);
TerrainLayerBuilder.Build(new TerrainLayerSpec { ... });
```

Material defaults (D4): URP/Lit metallic workflow, mask in `_MetallicGlossMap` and `_OcclusionMap`, `_Metallic` 1, `_Smoothness` 1 (mask alpha), smoothness from metallic alpha; no mask → metallic 0, smoothness 0.3. H map → `_ParallaxMap` 0.015. E map keeps `_EMISSION` even when black (practical lamps drive `_EmissionColor`). Foliage sets with alpha → clip 0.5, two-sided. Tiling `1 / tile_m`; detail tiling relative to the base UV (URP). Spec rows understand `render_face`, `zwrite` (Shader Graph only), `DrawOrder` on decals, `terrain_layer`, `assign_to_slot`, `detail{}`; a missing project shader ("SG_CRTScreen (WP09)") falls back to URP/Lit with one warning until it exists.

## 4. Editor steps for the integrator (editor holder)

1. Slot start as usual (`land.py --status`, refresh, console). The rules are already active; nothing to install.
2. Before copying content: `python3 Tools/build/validate_assets.py --ready` (fix errors with the owner; warnings are budget signals) and, in the editor, **LongShadow/Import/Compare Rules With Ready Notes** (expected remaining differences are the deliberate ones in DECISIONS: ground aniso 8, detail albedo linear, FX emissive q70, intel 1024).
3. Copy: `python3 Tools/build/copy_ready.py <wp> [--only <sub-path>] --validate` (area by area; Crunch makes big texture batches slow: hundreds of textures can take tens of minutes).
4. In the editor: `AssetDatabase.Refresh()` (imports with the rules), then **LongShadow/Materials/Build From Ready Specs** (rows whose textures have landed), then **LongShadow/Materials/Build All Texture Sets** (only sets that no spec row targets; the spec row is authoritative, so the order does not matter), then **LongShadow/Materials/Bind All Model Materials**, then **LongShadow/Import/Check Rules (Report)** (must say 0 mismatched; opted-out assets are listed).
5. After editing `Tools/build/asset_budgets.json` or a manifest `budget`: **LongShadow/Import/Reapply Rules (All Game Assets)**, then **LongShadow/Import/Export Rule Table (validate_assets.py)** and `python3 Tools/build/validate_assets.py --check-mirror` (0 mismatches expected).
6. To re-prove the rules (e.g. after a Unity upgrade): **LongShadow/Import/Run Rule Self-Test** (stages RawAssets samples in `Assets/__ImportRuleTest`, checks, deletes; long: call `ImportRuleSelfTest.Stage()`, `Verify()`, `Cleanup()` in separate `Unity_RunCommand`s). It also fails when a compressed rule ends up imported uncompressed on WebGL.
7. EditMode tests: `TestRunnerBridge.RunEditMode(null)`; clear the console afterwards (expected `LogAssert` noise). `ImportRulesImportTests` write into and delete `Assets/__ImportRuleTest`: do not run them while a self-test is staged.
8. Optional diagnostics: **LongShadow/Import/Explain Rule For Selection**, **Verbose Rule Logging** (logs every resolved rule on import), **LongShadow/Materials/Pack Mask From Selection**, **Build From Selected Texture Sets**, **Build From Spec File...**, **Bind Model Materials (Selection)**.
