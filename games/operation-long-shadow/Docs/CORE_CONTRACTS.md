# Core contracts reference

Generated by `Tools/build/gen_core_contracts.py` from the landed sources (`Assets/_Game/Scripts/Core`, `Assets/_Game/Scripts/Input`). The C# files and their XML docs are the contract; this page is the index. Changes are additive only and go through `Docs/CORE_CHANGES.md` (TECH_PLAN §6).

How systems use it: register your service in `Awake` with `GameServices.Register<IMyService>(this)`; look services up lazily with a `ServiceRef<T>` field (`_audio.Value?.Play2D(...)`), never by scene reference; find level markup by id through `IMarkerRegistry` (ids in `Assets/_Game/Data/markup_ids.csv`); raise and subscribe to `GameEvents` (subscribe in `OnEnable`, unsubscribe in `OnDisable`); look assets up through `Libraries.Get<T>()` (runtime) or `AssetManifest.Find<T>(id)` (editor builders) and fall back to `Placeholders` when an asset has not landed (log with `LSLog.MissingAsset`). Every static resets on `SubsystemRegistration` (domain reload is off, R6).
