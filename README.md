# Browser Games

A collection of playable browser game projects and their checkpoints.

## Sunline City

[Play now](https://sunline-city-summer.fal-ai-3289.chatgpt.site/) · [Source and controls](games/sunline-city/README.md) · [Gameplay demo](games/sunline-city/demo/sunline-city-action-demo.mp4)

An original 2D coastal open-world game with tiny characters, fast cars, gunfights, heists, checkpoint races, drifting, and stunt jumps. Explore ten neighborhoods, take on story jobs and repeatable adventures, customize cars, and collect photo postcards.

[![Watch the Sunline City gameplay demo](games/sunline-city/demo/sunline-city-demo.jpg)](games/sunline-city/demo/sunline-city-action-demo.mp4)

**Watch the 30-second demo:** gunfights, nitro, a heist getaway, drifting, a bounty shootout, and weapon selection, with original game audio. [Open or download the 1080p MP4](games/sunline-city/demo/sunline-city-action-demo.mp4).

### Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
cd games/sunline-city
npm ci
npm run dev
```

Open the local URL printed in the terminal. Run `npm run build` for a production build and `npm run preview` to preview it.

## Stillwater — ASCII Exploration Adventure

[Source and controls](games/stillwater-ascii-adventure/README.md) · [Version 1.0.0 checkpoint](https://github.com/GencSaracaydin/browser-games/tree/stillwater-ascii-v1.0.0/games/stillwater-ascii-adventure)

Explore a forgotten lakeside abbey rendered entirely in colored ASCII characters. Guide a cloaked traveler through grass and ruins, watch the water reflect the world, gather three echoes, and unlock the altar ending. Includes desktop and touch controls, three color palettes, a map and journal, optional ambient audio, and locally saved progress.

### Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
cd games/stillwater-ascii-adventure
npm ci
npm run dev
```

Open the local URL printed in the terminal. Run `npm run build` for a production build and `npm run preview` to preview it.
