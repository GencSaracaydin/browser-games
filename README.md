# Browser Games

A collection of playable browser game projects and their checkpoints.

## Stillwater — ASCII Exploration Adventure

[Source and controls](games/stillwater-ascii-adventure/README.md) · [Version 1.0.0 checkpoint](https://github.com/GencSaracaydin/browser-games/tree/stillwater-ascii-v1.0.0/games/stillwater-ascii-adventure)

Explore a forgotten lakeside abbey rendered entirely in colored ASCII characters. Guide a cloaked traveler through grass and ruins, watch the water reflect the world, gather three echoes, and unlock the altar ending. Includes desktop and touch controls, three color palettes, a map and journal, optional ambient audio, and locally saved progress.

### Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
cd games/stillwater-ascii-adventure
npm ci
npm run dev
```

Open the local URL printed in the terminal. Run `npm run build` for a production build and `npm run preview` to preview it.
